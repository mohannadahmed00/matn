01 · Design direction

A well-set book that happens to speak.

Matn is a memorization companion, not a media app. So the page comes first and the machinery comes second: type is set for long sessions, the surface is warm paper rather than glass, and every control that isn't in use recedes. The teacher's voice is the only thing that moves.

The palette stays where it is — deep olive, warm paper, muted gold — but it gets fixed where it was weak, and a dark theme derived as its own warm night paper rather than an inversion of day.

02 · Navigation consolidation

Seven routes become four. Four desktop destinations become three.

Rule applied to every surface: if it does not need its own back-stack entry, its own scroll position, or its own deep link, it is not a route. Everything else becomes a sheet, a dialog, a menu, or an inline region.

3.4 Iconography

One set, 24×24 grid, 1.75dp stroke, round caps, round joins, 2dp corner radius on terminals, no fills except the play triangle and the bookmark's active state. Optical sizes 20 / 24 / 40; stroke stays 1.75dp at 24 and scales to 1.5dp at 20 and 2.25dp at 40. Drawn as Compose ImageVector with a shared 24dp viewport — replacing the current hand-drawn glyphs, which vary between 1dp and 3dp.

04 · Logo & brand mark

The Marked Line

Three lines of text; the middle one is the one you are holding in memory — gold, thicker, and running past the block on both sides because a memorized line outlives the page it sat on. Two rectangles and a bar: no gradient, no shadow, no letterform to break at 16px. The dot above is the ن's point, kept as the mark's only asymmetry.

07 · Motion

Four curves, nine moments

The whole vocabulary is four easings and a duration ladder of 90 / 140 / 180 / 220 / 250 / 400 / 620 ms. Nothing bounces, nothing overshoots except the one goal-met bloom. Reduced motion is a real spec, not a switch that disables everything: state still changes visibly, it just changes by crossfade.

object MatnEase {
  val standard   = CubicBezierEasing(0.2f, 0f, 0f, 1f)
  val decelerate = CubicBezierEasing(0.05f, 0.7f, 0.1f, 1f)
  val accelerate = CubicBezierEasing(0.3f, 0f, 0.8f, 0.15f)
  val linear     = LinearEasing
}

object MatnDur {
  const val fade = 90;  const val quick = 140; const val menu = 180
  const val sheet = 220; const val bar = 250;  const val page = 400
  const val bloom = 620
}

// one place decides whether motion runs
@Composable fun  matnTween(
  ms: Int, easing: Easing = MatnEase.standard
): TweenSpec {
  val reduce = LocalAccessibilityManager.current?.reduceMotion ?: false
  return tween(if (reduce) MatnDur.fade else ms,
               easing = if (reduce) MatnEase.linear else easing)
}

09 · Shared UI module

What to build first, and its API

Everything below lives in :shared:ui and is consumed by both clients. Rule for the module: a component takes data and lambdas, never a ViewModel, never a navigation controller, and never reads a repository. Nothing in :shared:ui knows whether it is running on a phone or a desktop — callers pass the window size class down.
